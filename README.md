# Data-Driven-Market-Expansion-Analysis
This project analyses Tokyo Airbnb market data.

## Project Overview

This project analyzes Tokyo Airbnb market data to evaluate accommodation pricing, geographic differences and competitive dynamics.

The objective was to translate market insights into strategic recommendations that could support GoTrip's international expansion planning and market selection decisions.

---

## Business Problem

As the sharing economy continues to grow globally, understanding market attractiveness is critical before entering a new market.

Key business questions included:

- Which markets demonstrate strong demand potential?
- What pricing patterns exist across different locations?
- How competitive is the marketplace?
- What factors should influence expansion decisions?

---

## Project Objective

Evaluate market attractiveness using data-driven analysis and provide recommendations on potential expansion opportunities.

---

## Data Analysis Process

### Data Cleaning

Performed data preparation and transformation using Python:

- Missing value treatment
- Data standardization
- Data transformation
- Data quality validation

### Exploratory Data Analysis (EDA)

Analyzed key market indicators including:

- Demand and supply trends
- Pricing distributions
- Geographic differences
- Host activity patterns
- Tourism-related trends
- Growth indicators

### Data Visualization

Created interactive dashboards using Power BI to communicate key insights and support business decision-making.
